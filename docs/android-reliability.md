# Android 可靠性与任务体验更新

实施方案见 [分阶段计划](superpowers/plans/2026-09-13-android-reliability.md)。

## 新增入口

- 聊天右上菜单 → **任务成果**：查看此会话的图片、文档及其他文件，点击预览或分享；按修改时间排列，可手动刷新。它包含会话输入附件及工作文件，不把所有文件都声称为 AI 生成成果。扫描有深度/数量限制，隐藏文件和依赖目录不列出，完整目录可继续用原有文件浏览入口。
- 聊天右上菜单 → **任务预算**：可选择 10 / 25 / 50 / 100 / 200 轮。默认沿用 200 轮，对本机后续运行生效；接近上限时提醒，达到上限可手动继续。这是执行轮数限制，不是金额限额；重试、工具调用与继续执行可能产生额外用量。
- 服务商设置 → **测试调用**：由用户主动发起简短文本请求，检查实际调用能力，而不只是能否获取模型列表。运行会消耗接口用量；本次开发不自动使用用户账户调用。

## 修复内容

- 普通 Claude API Key 不再依赖 OAuth 专用标识配置。
- 模型输入与产物保存统一按调用会话隔离；文本、JSON、直接媒体输出均保留实际附件。
- 图片下载 HTTP 失败、空响应或错误页不再当作有效图片；无法读取指定系统文件也明确失败；输出只接受绝对 Linux 路径，拒绝会写错位置的 file URI。
- 凭据存储异常不再删除共享主密钥或静默新建明文存储；加密不可用时保留原始数据并提示临时模式。
- 无界面执行和定时任务使用当次运行结果，分别处理失败、取消、超时和未启动。
- 终端清洗保留合法 null 和空白，修正回车覆盖丢字符、私有 CSI 乱码和 OSC 吞文本。
- 日志记录和分享脱敏，避免命令参数与授权信息原样导出。

## Windows 构建

在现有工程运行 `scripts/build_android_windows.ps1 -RunAllTests`，即可使用已配置的本机工具跑完整单测并生成 debug APK。已有 `-RunModelTests` 参数继续保留。

## 验收边界

2026-09-13 使用本机 Windows 构建脚本完成全量验证：144 个测试类、1297 项单测全部通过，无失败或跳过；debug APK 构建成功，ZIP、原生依赖架构及 v2 签名检查通过。没有连接 Android 设备时，编译与单测不能替代真机：需重点验证 Keystore 异常、后台/定时任务、取消恢复、成果预览分享与测试调用入口。OAuth 的实际服务端权限和可用模型仍由服务商决定。
