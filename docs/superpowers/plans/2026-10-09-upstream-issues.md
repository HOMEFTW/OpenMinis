## 实施结果与边界

- #426：固定正则复用，消除横线匹配的递归风险，限制富文本解析输入/嵌套、严格缓存预算，修复流式节流被更新重置。超大原文保留并使用有界预览与惰性分块全文查看。原生 ICU/Scudo 的设备端改善仍需长会话压测。
- #423：认证、刷新与聊天共用 Claude CLI 2.1.280 指纹；删除模型发现日志里的认证头输出。本次未增加运行时自动追踪 npm 版本；未来服务端提高最低版本仍需更新这个唯一常量。
- #412：补上“小于字节预算但超过 8192 像素”的发送边界检查，超限图片强制缩放，不把原图缓存为可直接发送。
- #431/#406：android-speech 复用已有系统/服务商 ASR，支持本地音频解码与转写；共享麦克风互斥，处理超时、取消、路径边界和音频大小/时长上限。实际系统服务、MediaCodec 和外部 ASR 未真机联调。
- #258/#417：采用显式 HTTPS 端点 PEM CA 配置，仅绑定主机与端口，保留证书链和主机名校验，支持清除恢复默认信任。新请求动态读取配置；外站图片下载按下载地址选客户端，不继承 API 端点 CA。自动审批拒绝了全局信任用户证书方案，默认 network_security_config 保持未修改。
- #357：设置中新增全局每日日志注入开关，默认开启；关闭不禁用 GLOBAL.md 或记忆工具。降低日志变动造成的提示词波动，但不承诺模型切换、技能/MCP变化时仍命中完整历史缓存。
- #434：发现 timeout 被恢复筛选排除；现允许超时任务在旧运行异步收尾完成后恢复原子会话，尊重队列/并发限制，禁止恢复活跃或已完成任务。修复恢复按钮在再次超时后的锁定。
- #427/#425/#424：相同报告中的原生断言仍在当前 1b444ee 源码。识别这条明确断言后，当前进程后续 Shell 启动改用现有 PROOT_NO_SECCOMP 兼容路径；不自动重放原命令，不修改原生状态机。这是针对 seccomp 断言的缓解，不证明所有挂载/FUSE故障已解决。
- #430：提示词区分内部执行术语与面向用户的自然表达；实际输出质量需要模型对照，未做付费 API 测试。
- #433/#215：保留已有草稿/技能描述恢复实现，补充生产 ComposerDraftStore 的恢复、提升和附件草稿回归。#404 复用既有压缩工具配对测试。#414 的旧正文空白点击入口未发现活动提供者，不重复添加改动。
- #437/#432/#428/#429：iOS或缺少必要复现信息，不把 Android 源码修改冒充这些报告的修复。

独立审查发现并修复了 CA 客户端拦截 CDN、超时旧收尾覆盖新任务、兼容模式下同模式重复执行三处本次引入问题。
