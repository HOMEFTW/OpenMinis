# Android 日常使用功能实施计划

范围：仅 Android，完成八项建议；保留未提交的启动/返回修复，不自动提交、推送或发布。不调用真实付费模型接口。

## 现状

已有会话编辑、流式重试、单会话产物浏览、服务商文本调用测试，以及 JSON/文本导出和分类备份。草稿主要存放在进程内，启动“上次会话”按更新时间选择，缺少跨会话任务/作品入口。优先复用现有实现。

## 实施顺序与验收

1. 启动设置：记录实际查看的会话及时间；“上次会话”优先恢复最后查看且仍存在的会话，自动模式按查看时间判断；保留新建/列表选项、首次设置与崩溃保护。测试删除会话、无记录、超时和时间异常。
2. 草稿保存：持久保存每会话文字及附件元数据；恢复时只接受仍可读取的附件；发送/清空同步清理，草稿转正式会话迁移。新建草稿也能在重新启动后找到。测试序列化、损坏记录、附件过滤与会话隔离。
3. 失败恢复：对鉴权、额度、限流、超时、断网及普通失败给出不同处理提示；保留手动重试，避免对不可重试错误建议盲目重复请求。测试分类优先级。
4. 任务状态中心：集中展示内存中的运行/排队/失败任务及等待确认状态，能停止活动任务并跳转会话；明确进程结束后不把旧状态当运行中。复用 runId 状态与确认门。
5. 消息编辑与分支：核对已有编辑/分叉逻辑，为修改旧问题保留原会话并在新分支继续；原会话不得截断。测试分支边界与失败时原记录不变。
6. 统一作品库：从会话列表进入，跨会话列出本地作品，按文件名过滤，预览/保存/分享/返回来源会话；复用现有安全文件扫描与预览。限制扫描数量，IO 不阻塞主线程。
7. 配置连接测试：复用真实文本测试入口，补充所选模型能力说明及不支持项目提示；能力来自配置元数据，不能把文本测试成功描述为已验证生图。不给不兼容模型提供思考/生图选项。
8. 导出与备份：增加 Markdown 流式会话导出；备份开始前展示所选范围、预计体积和是否包含凭据，复用既有加密选项。测试 Markdown 内容与转义，检查估算和实际选项一致。

## 验证与交付

按功能执行针对性 JVM 测试；最后运行 Android 现有单测并构建 APK，检查包和签名。记录真机待验收项，不声称已验证系统回收、返回手势或真实 API。交付实施结果、限制、APK 和验证记录。

## 风险

草稿附件权限会失效，须提示而非静默伪装恢复；分支复制失败不能删除原历史；全库文件扫描必须限量且不追踪符号链接；备份体积是估算，压缩/去重后大小不同。模型元数据并不能证明服务端实际支持。

## 执行结果

八项实现均已接入，入口、具体行为和边界见 [Android 日常使用增强](../../android-daily-use.md)。新增草稿箱用于找回未发送的新对话；编辑分支使用独立媒体副本，避免原会话清理破坏分支附件；草稿转正式会话使用当前快照原子迁移，避免已发送文字复活。

验证包含完整 JVM 单测、APK 构建和新增 Room 设备测试的单独编译。设备实际运行仍受本机无设备限制；整套既有设备测试存在 mountedSessionId 引用失效，未修改无关测试。最终测试计数和安装包哈希记录在任务工作目录的 daily-use-verification.json。
