# Agent 稳定性第一批

基线：本地 a55d9ee，上游公开源码 b4c0661。beta build32 标签仍指向公开 1.14 源码；不将发布说明视为完整可移植实现。

范围与顺序：
1. 请求发出前校验工具调用/结果配对，解析结构化思考；保留现有模型、图片预算和协议适配。
2. 以当前模型轮次识别空回复/仅思考回复，一次恢复后失败提供继续；输出截断明确显示。
3. 在摘要前渐进清理旧思考并卸载旧工具输出，保护最近内容与原始历史；区分字节超限与 Token 超限。
4. 区分不可重试 TLS 错误、网络/无进展超时；为 OpenAI 兼容服务商提供独立等待时长。
5. OAuth 刷新失败保留凭据，拒绝刷新时标记重新登录，避免旧刷新结果覆盖新登录。

验收：针对上述决策和实际请求格式增加回归测试，运行 scripts/build_android_windows.ps1 -RunAllTests；检查差异。未连接设备/真实服务时明确说明。保留 100MiB 图片预算、上下文二级设置、会话通信和 GPT-6.1 Sol 默认 high。第一批不包含子代理体系、Shell 架构迁移、更新渠道和 UI 重设计；不提交或发布。
