# Android 输入区模型与思考强度选择

## 布局与交互

采用类似 ChatGPT 的简洁输入区样式：模型和思考强度入口位于文本输入区域下方、附件与发送工具栏上方；顶部保留会话标题。

- 模型入口显示当前模型和下拉箭头。弹出列表支持搜索模型名、模型 ID 和服务商名，勾选当前项；隐藏模型和禁用服务商不列出。
- 模型分组可在列表中直接选择。切换到当前分组内的模型时保留分组关联。非文本模型保留原有提示。
- “更多模型与分组”打开原有详细选择器，保留分组管理与模型测试。
- 思考入口显示实际可用强度。点击后打开分档滑块，第一档为“关闭”，末档为当前模型支持的最高强度；Astra 默认最高为 Max；旧 Ultra 偏好按 Max 兼容发送。
- 拖动时预览档位，松手后保存，避免拖动过程中频繁写配置。“/thinking”面板复用同一滑块。
- 切换到上限较低的模型时，滑块显示可用上限并解释原设置，直到用户主动拖动前保留原来的较高偏好。
- 使用主题自适应的中性色；长名称省略、列表滚动，并提供可访问性标签和滑块状态。

## 验证范围

档位映射测试覆盖 Astra 全档位、模型降档、非连续能力列表和无可用档位。使用本机现有构建环境完成验证：145 个测试类、1301 项单测全部通过，无失败或跳过；APK 构建、完整性、原生依赖及 v2 签名检查通过。未连接 Android 设备，无法以编译结果替代键盘遮挡、拖动手感、窄屏和大字体的真机验收。
