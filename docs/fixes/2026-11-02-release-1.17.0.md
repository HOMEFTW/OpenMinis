# Android 1.17.0 发布记录

日期：2026-11-02。发布仓库：`HOMEFTW/OpenMinis`；标签：`1.17.0`；versionCode：`32`。本次提交包括此前完成的稳定版同步、Forge 移植、Grok 背景和首页更新，源码标签与 APK 保持对应。上游基线为 Android 1.15 稳定版提交 `6eda5523a9c14fa8edc4fd9fb72e643fe47f23be`，不包含 1.16 Beta。

## 发布内容

- 新增 Grok 金发双马尾背景，与 GPT、DeepSeek、Claude 一起按真实模型 ID 自动切换；支持会话背景开关、全局默认透明度及会话独立透明度。设置页使用两列四款预览，人物在输入框上方完整显示。
- 手机独立运行 Forge API 2 适配层，新增无限画布、信息统计、Codeg 技能包和待办清单；从设置或聊天右上角菜单进入，无需连接电脑。
- 无限画布支持节点、分组、连线、图片／文件附件、自动保存、撤销重做和删除恢复；模型与界面使用同一数据服务和版本冲突检测。
- 待办提供个人／当前会话清单、状态、备注、排序、计划时间和变更记录；支持 AI 按权限读写。计划时间仅记录安排，不自动运行 AI。
- 内置四组 37 项 Codeg 技能及完整参考资源，默认停用，支持全局启用、会话覆盖和恢复继承。管理页可启停四个内置插件，停用保留数据；暂不支持第三方插件安装、卸载、更新或市场。
- 信息统计显示本机会话用量、请求速度和上下文占用；模型指纹检测需用户主动触发，会消耗服务商额度，结果仅供参考。
- 对齐上游 Android 1.15 稳定版（build37）公开源码，补齐模型／工具协议、空回复与拒绝处理、上下文裁剪、助手提问持久恢复、定时及子代理收尾、500 轮上限等行为。未合入上游 1.16 Beta。
- 新增 Tailscale、代理及服务商／用途路由，覆盖模型、Shell TCP/UDP/DNS、WebView 与 rclone；路由失效时明确阻断，保留手动恢复直连。
- 完善聊天搜索、分享、工具折叠、长思考显示、语音回退、备份与会话清理；应用更新继续使用本 fork，并增加缓存、按 ABI 选包、SHA-256 和安装身份校验。
- 保留 GPT high／Fast、原生 DeepSeek、会话链接与通信、上下文设置、100 MiB 图片预算及三套品牌图标。更新 PRoot／rclone 原生依赖和统一 Windows 构建脚本；固定技能文件原始字节，避免 Windows 换行转换破坏哈希校验。
