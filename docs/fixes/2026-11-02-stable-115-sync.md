## 验收过程中补齐的遗漏

- 智谱语音使用专用 `/api/paas/v4/audio/*` 端点；语音协议参考向量随源码保存。
- 技能浏览器接入本地代理认证，与其他 WebView 使用相同路由。
- 段落和标题的空白点击区域铺满行宽；键盘听写时滚动不强制隐藏输入法。
- 可恢复重试只更新徽标与详情，详情持续接收新重试；回滚保持 partial text 和等待状态。
- 文件工具的 I/O 工作线程保留同路径互斥；中断时保留线程标记并返回工具失败结果。
- 孤儿子会话删除在事务中复查固定树、父会话、近期更新及消息；中途失败整笔回滚。用户在提交前打开会话会取消该树的清理，提交后读取通过协程等待，不阻塞主线程。
- 用量总览与趋势图统一缓存上报口径；缺少缓存数据的未知请求不稀释已知命中率。

阶段交接归档保存在同目录的 `2026-11-02-stable-115-*-checkpoint.md`，其中待办仅反映当时状态。
