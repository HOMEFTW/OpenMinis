# Android 1.17.1 发布记录

日期：2026-11-27。仓库 `HOMEFTW/OpenMinis`，版本 1.17.1 / versionCode 33，包名 `com.openminis.app`，Android 8.0+、ARM64，沿用本 fork 调试签名。

## 发布内容

- 修复公开构建中任何模型点击发送都会触发 `ANTHROPIC_OAUTH_IDENTIFIER_PROMPT is not configured` 的问题。仅 Claude OAuth 路由读取其必需配置，其他模型正常进入请求流程，重试和模型回退使用相同修复。
- Forge 面板等待 WebView 挂载并取得有效尺寸后加载；增加原生加载指示、启动失败提示、返回和重试入口，覆盖资源加载及渲染失败。内置插件列表明确当前不支持第三方安装。
- 高速模式仅适用于 GPT 文本模型。切换到其他模型时关闭并保存，切回 GPT 需手动开启；请求构造时同步过滤非 GPT 的高速参数。
- 同步上游 1.15 的 Tailscale 出口节点维护补丁：域名优先 IPv4、本机回环保持直连、出口离线拒绝 TCP/UDP、无 IPv6 出口时调整 Shell AAAA 回答；重建 Android 原生库。
- 更新 README 下载入口和当前行为说明。保留已有品牌、四款背景、四个 Forge 内置插件、会话通信与链接、模型接入和上下文设置。

## 验证与产物
