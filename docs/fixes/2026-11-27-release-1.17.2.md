# Android 1.17.2 发布记录

日期：2026-11-27。仓库 `HOMEFTW/OpenMinis`，版本 1.17.2 / versionCode 34，包名 `com.openminis.app`，Android 8.0+、ARM64，沿用本 fork 调试签名。

## 发布内容

- 修复 Anthropic 兼容中转的模型目录解析。支持标准 `data` 数组及已有 OpenAI 兼容路径支持的目录格式，包括顶层数组、`models/items/results`、嵌套列表、字符串条目和 `model_id` 等字段；保留服务端返回的各厂商模型 ID。
- 单条无效模型记录被跳过，其他有效模型继续保留；保留 GPT、DeepSeek 的已知思考与上下文默认值，以及端点实际报告的限制。
- 消息接口路径返回 HTML 等无效目录时，继续查找父路径的模型接口，并跳过重复 URL。
- 自定义 API Key 服务不再自动填充内置 Claude 模型。读取失败时显示错误原因，保留已有列表；官方端点和 OAuth 的预置目录保持原策略。
- 无密钥本地服务的模型发现不再携带空鉴权头；官方地址识别按主机名判断。模型列表的兼容解析继续使用用户选定的 Anthropic 消息协议。
- 升级版本与 Android versionCode，更新 README 下载入口、使用指引及本记录。

## 更新后操作

从 [Release](https://github.com/HOMEFTW/OpenMinis/releases/tag/1.17.2) 下载 `app-debug.apk`，同签名旧版可覆盖安装。更新后打开对应服务商设置，点击“刷新模型列表”。接口实际开放的模型与账号权限决定最终可用范围。
