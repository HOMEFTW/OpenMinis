# Codex Forge Android 接入

## 目标

以本地 `D:/Code/codex-forge` 0.3.2 / Forge API 2 为来源，让 OpenMinis 在手机上独立运行无限画布、信息统计、Codeg 技能包和待办清单，不依赖电脑服务。不继续同步 OpenMinis 1.16 Beta，不改版本、不提交或发布。

## 实施计划

1. 保留 Forge 的 React 画布交互、SDK 及数据协议，将桌面 IPC 改为受限 Android WebView 桥。提供 API 2 能力查询、权限校验、插件独立存储、可信会话绑定和草稿比较后写入；不宣称支持桌面 Node/Electron 能力。
2. 在应用私有目录持久保存画布和待办，UI 与模型使用同一服务。保留 expectedRevision 冲突检测、原子批次、撤销重做、删除恢复以及手机文件选择。
3. 信息统计接入 OpenMinis 的真实会话数据和模型配置，移植指纹参考算法；主动检测仅由用户点击触发，使用隔离请求，未知模型和缺失数据明确显示。
4. 内置四组 37 项 Codeg 技能与完整支持资源和许可证，默认停用，启用后进入现有技能系统；保留用户技能及会话覆盖。
5. 从应用设置及会话菜单进入插件；按手机屏幕调整界面。验证存储冲突、权限/路径/会话隔离、模型工具、统计及技能生效，再用项目脚本构建并校验 APK。

## Android API 2 范围

- 入口：设置和会话菜单的 Forge 插件；启停仅控制本机插件，保存的数据保留。
- 支持上下文、清单、能力查询、插件设置/存储、事件、当前会话草稿 CAS、标题、输出及面板。每次调用检查插件声明和所需权限，网页不能更换可信会话绑定。
- `panels` 对应手机全屏插件；`sidebar/toolbar/composer.register` 映射到当前插件页的操作按钮；`output` 显示当前插件页输出区；`browser.open` 交给 Android 外部浏览器。能力返回明确标记 `host=openminis-android`。
- WebView 只加载专用 origin 下的本地资源；没有文件/内容 URL 访问和任意远程导航。模型仅能通过 `forge` 访问画布、待办和已启用技能，不能主动启用插件或技能、删除整张画布、触发模型检测。
- 不包含 Node/Electron、DSH、桌面窗口控制、第三方插件安装或电脑数据同步；未支持能力明确返回错误。

## 已知边界

未连接 Android 设备；仪器测试仅编译，尚未执行安装、真机触控、WebView 返回键、文件选择及外部文件查看器测试。未调用真实收费服务商，主动指纹检测需用户在手机上验证。

待办计划/延后时间为记录字段，不自动运行 AI。技能默认停用，启用不自动安装 OfficeCLI/Python 等依赖，也不运行脚本。信息指纹仅供对照，未收录模型不生成替换结论。Forge 本机数据暂未纳入原有自定义备份导出；卸载前需自行保留必要内容。

所有修改均保留在本地工作副本，未提交、未推送、未发布；原有稳定版同步修改保留。
